# DARK SCHOOL — Legendary Edition

لعبة رعب ثلاثية الأبعاد في المتصفح بمنظور الشخص الثالث. الأستاذ كريم كان معلّمًا طيبًا، وبعد وفاة زوجته ليلى تحوّل حزنه وغضبه إلى كابوس يطارد الطلاب. أنت طالب (عمر) بقي في الاحتجاز؛ عليك كشف أسرار المدرسة والهروب منها — أو إنهاء الكابوس إلى الأبد.

> **النسخة الأسطورية (v2.1):** أدوات تشتيت تُرمى، تحصين الأبواب بالكراسي، مخابئ تحت الأثاث، دعم ذراع التحكم، وضع آمن للحساسية الضوئية، و3 خانات حفظ.
>
> **(v2.0):** 8 لغات واجهة (الإنجليزية هي الأساس)، 4 نهايات منها نهاية سرية، 16 إنجازًا مع أرشيف دائم، آثار ليلى الثلاثة، نظام خوف، تطوّر الأستاذ على 3 مراحل، عواصف رعدية وشبح ليلى، وصعوبة «أسطوري».

**Primary language is English** — the game boots in English (`<html lang="en" dir="ltr">`). Arabic and six other languages are available instantly from the menu language picker; only Arabic switches the layout to RTL.

> **A 3D third-person horror game for the browser** built with HTML + CSS + JavaScript + **Three.js**. No Unity / Godot, no external art or audio files: characters, textures, sounds and music are generated procedurally at runtime.

## 1) الملفات

| الملف | الدور |
|---|---|
| `index.html` | هيكل الصفحة: القوائم، الـHUD، النوافذ المنبثقة، أزرار اللمس |
| `style.css` | التصميم، دعم RTL/LTR، الهواتف، تأثيرات الشاشة |
| `game.js` | كل منطق اللعبة (مقسّم لأقسام مرقّمة 0–10 في رأس الملف) |
| `i18n.js` | سجل اللغات الثماني والاتجاه (RTL/LTR) وتجميع حزم الترجمة |
| `lang/*.js` | حزم الترجمة: `extra.js` (نصوص v2.0 بالإنجليزية والعربية)، `pack2.js` (نصوص v2.1 لكل اللغات الثماني)، `es، fr، de، tr، ru، pt` |
| `.github/workflows/deploy.yml` | نشر تلقائي على GitHub Pages |

أقسام `game.js`: الأدوات والإعدادات ← محرك الصوت (WebAudio) ← المُصيِّر والجودة والتركيبات ← عالم التصادم وخط الرؤية وشبكة الملاحة (A*) ← بناء المدرسة ← الشخصيات والحركات ← اللاعب والكاميرا ← ذكاء الأستاذ ← منطق اللعبة والألغاز والنهايات ← الواجهة ← الحلقة الرئيسية والترجمة.

## 2) التشغيل محليًا

المتطلبات: Node.js 18+ .

```bash
npm install          # يثبّت Three.js وأدوات البناء
npm run dev          # تطوير: افتح الرابط الذي يظهر (مثلاً http://localhost:5173)
npm run build        # بناء نهائي → dist/index.html (ملف واحد يحتوي كل شيء، يعمل دون إنترنت)
npm run preview      # معاينة نسخة البناء
```

> يمكن أيضًا تشغيل الملفات الثلاثة الخام (`index.html` + `style.css` + `game.js`) على أي خادم ثابت مباشرةً: `index.html` يحتوي على *import map* يحمّل Three.js من CDN. افتحها عبر خادم (مثل `npx serve .`) وليس بالنقر المزدوج، لأن وحدات ES لا تعمل من `file://` في بعض المتصفحات.

## 3) النشر على GitHub Pages — خطوة بخطوة

### الطريقة أ: تلقائيًا عبر GitHub Actions (موصى بها)
1. أنشئ مستودعًا جديدًا على GitHub وارفع إليه كل ملفات المشروع (`git init && git add . && git commit -m "DARK SCHOOL" && git branch -M main && git remote add origin <رابط المستودع> && git push -u origin main`).
2. في المستودع: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. أي دفع (push) إلى فرع `main` يشغّل `.github/workflows/deploy.yml` الذي ينفّذ `npm ci && npm run build` ثم ينشر مجلد `dist`.
4. بعد دقيقة تقريبًا يظهر الرابط في تبويب **Actions** وفي **Settings → Pages**: `https://<اسمك>.github.io/<المستودع>/`.

> لا حاجة لضبط `base` في Vite: ملف البناء النهائي يضمّن (inline) الجافاسكربت والـCSS داخل `index.html`، فلا توجد مسارات نسبية قد تنكسر على صفحات المشاريع.

### الطريقة ب: يدويًا
1. نفّذ `npm run build`.
2. انسخ `dist/index.html` وحده إلى فرع `gh-pages` (أو مجلد `/docs`) وفعّل Pages من **Settings → Pages → Deploy from a branch**.

### الطريقة ج: دون أي بناء
ارفع `index.html` و`style.css` و`game.js` في جذر الفرع `main` وفعّل **Deploy from a branch → main / (root)**. تحتاج اتصال إنترنت لأن Three.js يُحمَّل من CDN.

## 5) ما الذي تحتويه اللعبة

- **مدرسة كبيرة** من طابقين (أرضي + قبو بسلم حقيقي): 3 صفوف، مكتبة، مختبر، مكتب مدير (بقفل رقمي)، غرفة معلمين، عيادة، غرفة حارس، كافتيريا، دورة مياه، موسيقى، فنون، ممران، بهو، وفي القبو: كهرباء، غلاية، أرشيف، مخزن، صيانة، ومقام سري. **غرفتان سريتان** (خلف رف المكتبة، وغرفة المقام بقفل مغناطيسي).
- **الأستاذ كريم**: مجسم مفصلي مرعب (جسد نحيل منحنٍ، عينان متوهجتان، وجه مرسوم، عصا) بحركات: مشي، ركض، بحث، صراخ، ضربة. ذكاء اصطناعي كامل: دورية بين الغرف ← يسمع الضجيج (الركض، الأبواب، الرموز الخاطئة، الهبوط من القفز) ← يرى اللاعب بمخروط رؤية وخط نظر يحترم الارتفاعات (الانحناء خلف الأثاث العالي يخفيك) وعدّاد انتباه تدريجي ← مطاردة بمسارات A* وفتح الأبواب ← فقدان الأثر والبحث عند آخر موقع ← تفتيش الخزائن القريبة ← العودة للدورية.
- **حركة الطالب**: مشي، ركض (تحمّل)، قفز (يمكن الصعود على المكاتب)، انحناء، اختباء داخل الخزائن مع **كتم النفس**.
- **مهمات وألغاز**: مصباح وبطارية تنفد، 4 مفاتيح، باب سري بكتاب أحمر، رمز رقمي مستنتج من القصة ومن ساعة الممر، فيوزات وصندوق كهرباء، إنذار ومطاردة غاضبة عند أخذ مفتاح البوابة.
- **أجواء**: إضاءة متقطعة (تتأثر بقرب الأستاذ)، انقطاعات كهرباء، ضباب، ظلال المصباح، موسيقى ونبض قلب وأصوات مولَّدة بالكامل (WebAudio) مع صوت مكاني، مفاجآت مدروسة (باب يُصفق، سبّورة تكتب، بيانو، همسات، صندوق موسيقى).
- **نهايات متعددة (4)**: *الليلة الطويلة* (هروب، بنسختين حسب معرفتك بالحقيقة)، *وداعًا يا ليلى* (إعادة الخاتم بعد جمع ≥ 6 من 8 صفحات — يمكن أيضًا عند الإمساك بك)، *رماد* (إفراط ضغط الغلاية)، و**النهاية السرية** *أسطورة مدرسة الظلام*: اجمع الآثار الثلاثة والخاتم و6 صفحات ثم أدِّ الطقس أمام مذبح المقام.
- **الأسطورة (Legendary):** ثلاثة آثار مخفية (صندوق موسيقى ليلى، قلادتها، صورة زفافهما) لكل منها مكان وأثر صوتي/بصري، شبح ليلى يظهر عند اكتشافها، ومذبح يفتح النهاية الحقيقية.
- **نظام الخوف:** مقياس يهبط في المطاردة والظلام وقرب الأستاذ، ويرتفع في الغرف الآمنة (العيادة، غرفة المعلمين)؛ الخوف المنخفض يضيف همسات، خطوات وهمية، وتشويشًا بصريًا يهدأ في الغرف الآمنة.
- **تطوّر الأستاذ:** كل 3 صفحات تُجمع ترفع مرحلته؛ تتسع رؤيته وسمعه وسرعته، مع ظهور هالة حمراء حوله في المراحل الأعلى.
- **16 إنجازًا** + **أرشيف الأسطورة** في القائمة الرئيسية: يعرض الآثار والنهايات والإنجازات المكتشفة، ويُحفظ في `localStorage` (الآثار والصفحات المكتشفة تبقى في الأرشيف حتى بعد بدء لعبة جديدة).
- **العواصف والشبح:** وميض برق مع رعد متزامن، وغبار متطاير في ضوء المصباح، وشبح يظهر في لحظات مدروسة (بلا مبالغة).
- **صعوبة «أسطوري (كابوس)»** في الإعدادات: أسرع وأحدّ حسًا وأقل رحمة، وتمنح إنجاز *Legendary* عند إكمال القصة.

### جديد في v2.1
- **أدوات تشتيت تُرمى (Q):** طباشير وزجاجات موزّعة في المدرسة. الطبشورة ضجيج متوسط، والزجاجة تتحطم بضجيج عالٍ (30 مترًا). الرمي بقذيفة حقيقية لها جاذبية وتصادم، وعند الارتطام يذهب الأستاذ إلى مكان الصوت — وإن كان يطاردك فقد يفقد أثرك. إنجاز *Misdirection*.
- **تحصين الأبواب (R أو زر 🪑):** تضع كرسيًا أمام باب مغلق خلال ثانية ونصف (شريط تقدّم، ويُلغى إن ركضت). الباب المحصّن يُغلق المسار في شبكة الملاحة فيسلك الأستاذ طريقًا آخر، وإن لم يجد يحطّمه بعد ~2.4 ثانية (أسرع في حالة الغضب) بضجيج عالٍ. حدّ أقصى حاجزان في الوقت نفسه، ويُحفظان مع اللعبة. إنجاز *Not Today*.
- **مخابئ تحت الأثاث:** 12 مكانًا جديدًا تحت المكاتب والأسرّة وطاولات الكافتيريا — كاميرا منخفضة ومجال نظر أوسع من الخزانة (ترى حذاءه)، وتفتيش الأستاذ لها لا يفتح بابًا بل يركع للنظر.
- **دعم ذراع التحكم (Gamepad API):** العصا اليسرى للحركة واليمنى للكاميرا، A قفز، B انحناء، X تفاعل، Y مصباح، LB رمي، RB/RT ركض، Start إيقاف، Back المفكرة، مع اهتزاز يتبع مستوى الخوف. يمكن إيقافه من الإعدادات.
- **وضع آمن للحساسية الضوئية:** يوقف ومضات البرق والإضاءة المتقطعة وحبيبات الفيلم واهتزاز الشاشة وتأثير الذعر، مع إبقاء اللعبة كاملة الوظائف.
- **ثلاث خانات حفظ:** كل خانة تحفظ تقدمها وصعوبتها وأدواتها وحواجزها، مع عرض المهمة الحالية والوقت والصفحات والآثار، وأزرار تحميل/بدء/حذف.
- **حفظ تلقائي** في `localStorage` ضمن **3 خانات** (نقاط حفظ عند الالتقاط/الفتح/كل 45 ثانية في الهدوء) + متابعة + إعادة من آخر نقطة.
- **اللغات الثماني**: الإنجليزية (الأساس)، العربية (RTL كامل)، الإسبانية، الفرنسية، الألمانية، التركية، الروسية، البرتغالية. تبديل فوري من زر اللغة في القائمة أو من الإعدادات، دون إعادة تحميل؛ كل لغة تغطي الواجهة والقوائم والملاحظات والنهايات والإنجازات (352 مفتاحًا لكل لغة، والإنجليزية احتياطية لأي مفتاح ناقص).
- **الأداء**: دمج الهندسة الثابتة في دفعات لكل مادة/قطعة (frustum culling)، مجموعة ثابتة من الأضواء الحقيقية تتبع أقرب التجهيزات، أضواء السقف عبر `InstancedMesh`، مواد Lambert في وضع الجودة المنخفضة، ظلال المصباح (إيقاف/512/1024/2048)، مقياس الدقة، **دقة تكيفية** تخفض الدقة تلقائيًا عند هبوط الإطارات، وإعادة استخدام الكائنات دون تخصيص ذاكرة في كل إطار.

## 6) ملاحظات صريحة عن الأصول

- **لا توجد ملفات أصول خارجية للرسوم أو الصوت**. الشخصيات هي هياكل مفصلية (hierarchy of joints) ببنية جسم كاملة (رأس، رقبة، عمود فقري، أذرع بمرفقين، أرجل بركبتين) تُحرَّك بـ`THREE.AnimationMixer` وكليبات مفاتيح (keyframes) حقيقية مع مزج بين الحركات — لكنها مبنية من أشكال ناعمة (كبسولات/كرات) مولّدة بالكود وليست نماذج GLTF منحوتة في برنامج نمذجة. إن أردت استبدالها بنماذج GLB مرخّصة (مثل CC0 من Quaternius أو Kenney)، ضع الملف في `public/` وحمّله بـ`GLTFLoader` داخل `buildStudent()` / `buildProfessor()` مع الإبقاء على نفس أسماء الكليبات (`idle, walk, run, ...`).
- الخطوط (Cairo / Special Elite) تُحمَّل من Google Fonts إن توفّر الإنترنت، وإلا تُستخدم خطوط النظام.
- Three.js بترخيص MIT.
- همسات الأستاذ الصوتية تستخدم `speechSynthesis` المدمج في المتصفح فقط إن وُجد صوت للغة المختارة (يمكن إيقافها من الإعدادات).

## 8) إضافة لغة جديدة

1. انسخ `lang/es.js` إلى `lang/xx.js` وترجم القيم (المفاتيح إنجليزية ثابتة).
2. أضف الملف إلى `i18n.js`: `import xx from './lang/xx.js';` ثم أضف `{ code: 'xx', native: '…', en: '…', flag: '🏳️', dir: 'ltr' }` إلى `LANGS` وأضف `xx` إلى `EXTRA_LANGS`.
3. إن احتاجت لغتك نصوصًا ناقصة فستظهر الإنجليزية تلقائيًا. حدّد `dir: 'rtl'` فقط للغات من اليمين إلى اليسار.
4. أعد البناء: `npm run build`.

## 5) نسخة تطبيق الكمبيوتر (Windows) عبر GitHub Actions

1. ارفع المشروع على GitHub (فرع `main`).
2. تبويب **Actions** ← **Build DARK SCHOOL (Windows app)** ← **Run workflow**.
3. بعد ~5 دقائق افتح التشغيلة الناجحة ونزّل **DARK-SCHOOL-Windows** من قسم Artifacts:
   - `DARK-SCHOOL-Setup-x.x.x.exe` — مثبّت عادي
   - `DARK-SCHOOL-Portable-x.x.x.exe` — نسخة تعمل بدون تثبيت
4. لإنشاء Release تلقائيًا: `git tag v2.1.0 && git push origin v2.1.0`.

محليًا: `npm install && npm run electron` للتجربة، و`npm run dist` لبناء الـ exe (على ويندوز). اضغط **F11** لملء الشاشة.
